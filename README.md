## 🎮 Guess The Number ##

Hey! thank you for taking a look at my first project!
This game is all about guessing the right number. The application will pick a secret number between 0 and 100, and you have to guess it in the fewest attempts possible!
* Note: no AI was used for this, since i wanted to learn and type everything my self

## Features aka what i learned ##
- Auto save: it saves your personal score in your local PC using by creating a simple JSON file after your very first game.
- Smart Initialization: Automatically makes a fresh save file
- Terminal interface: the game runs in your CMD for now, with plans of making a GUI for it

## How To Play ##
to play the game just type Start!
type score to view your lowest score!
type exit to close the game!
